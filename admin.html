Éditeur des données du site

Le fichier ci-dessous est un objet JSON qui représente les données centralisées. Modifiez-le, vérifiez sa validité, puis exportez un fichier data.json. Pour appliquer les changements sur le site, reportez ces données dans js/data.js (voir README.md). L'éditeur ne modifie pas automatiquement le site en ligne.

Comment publier une mise à jour ?

1. Modifiez les données ci-dessus et cliquez sur « Exporter data.json ».
2. Ouvrez js/data.js dans votre dépôt GitHub.
3. Reproduisez les modifications dans l'objet window.BLF_DATA (le fichier doit rester du JavaScript, pas un JSON brut).
4. Cliquez sur Commit changes. GitHub Pages republiera automatiquement le site après quelques minutes.

Pour une gestion multi-staff sans modifier le code, il faudra connecter un CMS avec authentification (par exemple Decap CMS avec un backend d'authentification, ou un CMS hébergé). Une interface publique seule ne peut pas sécuriser les modifications.
