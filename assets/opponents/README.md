# Logos des adversaires

Déposez ici les logos des équipes adverses au format PNG, JPG ou WEBP.

Dans `js/data.js`, ajoutez une entrée dans `opponentLogos` avec le nom de l'adversaire en minuscules et le chemin du fichier.

Exemple :

```js
opponentLogos: {
  "voltrik esport": "assets/opponents/voltrik-esport.png"
}
```

Le nom doit correspondre au champ **Adversaire** du formulaire Discord. Sans logo configuré, le site affiche automatiquement `assets/nologo.png`.
